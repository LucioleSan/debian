
# T CEN 500 – Project Management Simulation

## 📘 Description
 
Ce projet a été réalisé dans le cadre du module **T CEN 500** de la formation Pre-MSc à Epitech. Il s'agit d'une simulation complète de gestion de projet, autour d'une thématique technique (ex. robotique). Le but était d'appliquer les méthodes classiques de gestion de projet à travers une étude de cas réaliste, incluant la planification, les ressources humaines, le budget, les risques et la qualité.

## 🎯 Objectifs du projet

Le projet devait démontrer la maîtrise des éléments suivants :

- 📅 **Diagramme de Gantt** : Planification des actions et attribution des tâches.
- 🧠 **Compétences** : Identification des compétences nécessaires pour mener à bien le projet.
- 👥 **Profils** : Définition des profils, expériences, et salaires nécessaires.
- 🧰 **Ressources** : Listing du matériel nécessaire à la réalisation du projet.
- ⚠️ **Risques** : Identification d'au moins 3 risques, avec analyse de probabilité, impact, et actions de mitigation.
- 💰 **Budget** : Élaboration d'un tableau de budget complet (salaires, charges patronales, frais de location, etc.).
- ✅ **Qualité** : Définition de 3 aspects de la gestion qualité (tests, normes, amélioration continue...).
- 🗣 **Communication** : Élaboration de supports de communication (rapports, écrits, oraux).
- 🎤 **Présentation** : Présentation professionnelle du projet (slides, démo...).
- 🎯 **Perfection** : Respect des consignes et livrables attendus.
